# MemoryCloud™ Roadmap  
Owner: Jesse J. Lamont • Org: Lamont Labs • Version v4.3 • Date 2025-10-05  

---

## 1  Overview
The roadmap provides a transparent outline from demo → pilot → production readiness.  
It reflects real milestones, not speculative features.  
All phases enforce MemoryCloud’s founding principles: **privacy-first**, **deterministic recall**, and **fail-closed provenance**.

---

## 2  Milestone Phases

### Phase 1 — Demo (Current: v4.3)
✅  Status: Complete  
- Local FastAPI backend (capture / recall / audit / verify)  
- Deterministic sealed-box crypto with reproducible audit chain  
- CLI HUD ✔ / ! / ✖ indicator system  
- Full documentation bundle (binder + repo parity)  
- Verified reproducibility via `make verify`  

Deliverables:
- GitHub repo (demo seed)
- Demo bundle ZIP (for investors)
- Audit proof logs + SBOM
- Investor one-pager

---

### Phase 2 — Pilot Build (Planned)
Target: Q1 2026  
Goals:
- Enable opt-in cloud sync via encrypted tunnel (user-held keys)  
- Add recall search UI (browser + HUD app integration)  
- Begin limited enterprise pilot (under NDA)  
- File provisional patent and begin trademark registration  

Key Fixes:
- Hardware-backed key storage (Secure Enclave / StrongBox)
- Full E2EE channel encryption  
- Facial / voice redaction filter (Edge inference)  

---

### Phase 3 — Compliance & Certification
Target: Mid 2026  
Goals:
- Establish privacy certification (GDPR, FERPA baseline)
- Implement automated data lifecycle policies (deletion/export)
- Add enterprise admin console for audit oversight
- Integrate with external privacy auditors  

Expected Outputs:
- Audit report
- Compliance mapping (ISO 27001 draft alignment)
- Enterprise licensing model  

---

### Phase 4 — Productization / Acquisition Track
Target: Late 2026  
Options:
- Acquisition by privacy-focused wearable or AI assistant company  
- Spinout under Lamont Labs IP portfolio  
- Licensing for “Memory-as-a-Service” B2B integrations  

Negotiation Readiness:
- Full demo-to-production lineage  
- Patent filings finalized  
- SBOM + PROVENANCE proofs traceable to seed repo
